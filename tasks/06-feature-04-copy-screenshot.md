# User Story
En tant qu’utilisateur de l’extension, je veux copier la capture d’écran dans le presse-papiers, afin de pouvoir la coller directement dans une autre application.

# Critères d’acceptation
- Étant donné qu’une capture d’écran est affichée, quand l’utilisateur consulte la capture, alors un bouton « Copier » est disponible.
- Étant donné qu’une capture d’écran est affichée, quand l’utilisateur clique sur « Copier », alors l’image est copiée dans le presse-papiers du système.
- Étant donné que l’utilisateur a copié la capture, alors l’image disponible dans le presse-papiers correspond à la capture affichée.
- Étant donné qu’une capture est disponible, quand la copie échoue, alors un message informe l’utilisateur que la capture n’a pas pu être copiée.
- Étant donné que la copie a été effectuée avec succès, alors l’utilisateur est informé que la capture a été copiée dans le presse-papiers.

# Hors périmètre
- Enregistrement de la capture sur le poste

- Modification ou annotation de l’image

- Partage de la capture

- Choix d’une zone de capture
